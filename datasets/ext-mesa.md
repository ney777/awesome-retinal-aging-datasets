## Overview

Multiethnic prospective cohort with proven retina–event and retina–brain pairings, repeated CFP in a subset.

当前核验的影像与模态范围 — Fundus; brain MRI in subset

Image availability — Uncertain for archived retinal pixel files; BioLINCC route is for datasets; MESA ancillary project required for new analyses using stored source images when beyond released data.

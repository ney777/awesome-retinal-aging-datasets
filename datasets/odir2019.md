## Research value and experimental design

| Field | Recorded value |
| --- | --- |
| Individual linkage / 个体配对依据 | 每个患者一个 ID、年龄、性别、两眼图像，训练集有两眼医生关键词和患者级标签；测试阶段不提供关键词。 |
| Strengths / 主要优点 | 双眼共享患者键、多厂家、多中心。 |
| Limitations / 关键缺陷 | D/H 是阅片者利用双眼照片及年龄作出的分类，缺乏独立全身疾病确诊/发生时间；未核实中心 ID。 |
| Suggested experiments / 建议实验 | 双眼按患者分组，以年龄作连续标签；保留患者级划分，核对具体获准分卷及许可后做跨域外测。 |
| Retinal Aging suitability | A: 年龄和双眼照片记录在同一受试者行。 |
| Stroke / CSVD suitability | Unknown |
| AD / Dementia suitability | Unknown |
| Multicenter model suitability | G: 多设备多中心异质性；不能仅据机构数设计真实中心划分。 |
| Screening rationale / 筛查理由 | 年龄和双眼照片记录在同一受试者行。 \| 患者级 D/H 标记由阅片与年龄产生；临床确诊标签获取未证实。 \| 多设备多中心异质性；不能仅据机构数设计真实中心划分。 |

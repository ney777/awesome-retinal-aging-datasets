## Overview

北爱尔兰老龄队列，对照复核已有零结果；可区分 MoCA 定义和实际临床痴呆。

当前核验的影像与模态范围 — Fundus \| OCT (protocol)

Image availability — QUB safe setting / secure remote server by application. Health protocol documents scans; public UKDS documentation is not a raw image release.

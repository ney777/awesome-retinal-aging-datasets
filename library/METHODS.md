# 检索、归类与评分

## 数据边界

基础调查截至 2026-11-03；2026-11-06 的定点复核纠正了 CHS/AGES 神经方向评分，并补充 ARIC/CHS 用途限制，不代表全部资源在新日期重新核验。来源专属日期以 evidence.checked 为准，资源级 checked 保留原日期。计数单位是可引用的数据产品或受控队列入口。一个资源可以是原始数据、子集、衍生标注、组件、重打包或队列的一次研究发布。479 条主记录由 451 条基线和 28 条扩展组成；21 条基线及全部扩展做了重点来源复核。其余 430 条逐条接受冻结目录的范围筛查，没有重新人工验证每个当前下载入口。含已排除的记录，不报告“479 个独立患者队列”或跨库总患者数。

2026-11-03 检查时，EyeDataHub 的最高 Git 稳定标签与 PyPI 最新版本均为 v0.7.0，对应提交 `0ce7144459a41e8be255fed7fa62c30416613e6b`，上游检索截止 2026-08-02。先阅读并保留其规范，再从同一标签导入完整 CSV、JSON、身份/家族核验、来源/许可/传输核验、带单位的数量和关系边。原始快照有 446 个按上游规则定义的家族、145 条有来源的有向关系。家族规则会合并明确组件/任务视图，但允许衍生库拥有单独家族 ID，故家族数同样不能作为独立队列数。另从固定的更新提交读取 364 个 ID 的日期证据，分开标记首次公开、存储库发布及关联论文日期。[规范](inputs/v0.7.0/CLAUDE.md) · [基线清单](inputs/v0.7.0/manifest.json) · [日期补充清单](inputs/supplement/manifest.json) · [软件和数据快照引用](https://doi.org/10.5281/zenodo.21798623)

## 检索与筛查

1. **基线普查。** 以 `record_id` 作唯一键，比对 CSV 与 JSON，再关联 identity、quantity、audit。根据所含模态和资源描述筛选人眼后节像素或可与原图配套的标注，再检查易混记录。例如，前节 AS-OCT、眼动、角膜神经检查、动物/细胞实验、只有体积标量的 XLSX/CSV 均不自动纳入。眼底相关词只产生候选，不能直接升级临床证据。[筛查例外](inputs/screening_exceptions.json)
2. **专题发现。** 对 PubMed ESearch 执行四组 TIAB 检索，交叉 retinal imaging、fundus photography、OCT/OCTA 与年龄、卒中/CSVD/MRI、神经退行性疾病和死亡/心血管风险。限定出版日期至本次调查日，分别命中 33、60、149、49 条，合并后有 274 个 PMID；每次返回的 ID 数等于总命中数。另用中英文关键词检索队列、仓储与论文，沿数据可用性、参考文献和后续使用论文回查管理方。公开 PubMed 接口和官方网页用于替代当前会话未配置的文献 MCP。139 条查询日志是不同检索/核验步骤，可以重复命中同一资源；274 篇是发现集，没有将每篇都认定为完成全文审查。[检索式与处置](output/search_log.csv) · [去重论文表](output/pubmed_hits.csv)
3. **站点交叉检查。** 检查 Awesome Ophthalmology Dataset、PhysioNet、Grand Challenge、Kaggle、Hugging Face、Zenodo、Figshare、Dryad、Mendeley Data，以及 NIH/NLM、BioLINCC、CDC/NCHS、UK Biobank 和队列管理方。按国家/地区补查亚洲、非洲、大洋洲、南美及欧洲的公开发布和人群子队列。二级目录、论文题名、新闻和模型仓库只用于找到提供方。原始字段字典、文件索引、受试者映射和受控项目条款优先于聚合目录。
4. **分层核验。** 分开记录研究内有无同人关联、外部研究者是否有合法路径、能否获得像素，以及可否取得特定标签。核验层次包括上游冻结检查、项目网页/论文/字典，以及少数公开元数据或文件目录的实际核对。后者保留工作簿名、字段、匹配结果或校验码，不在本库分发患者记录。查到入口不代表下载成功；批准、原始文件和用途权限不相互替代。
5. **排除与待核。** 记录无后节影像、仅有组汇总或个体测量、前节成像等排除原因。论文内已配对而外部眼图供给未明，或者年龄字段、病例键、用途许可未能确认时，保留具体缺口。未查实一个字段不能将其当作阴性。资源库是有明确边界的专题调查，不估计全球检索召回率。[排除表](output/excluded.csv) · [证据明细](output/evidence.csv)

## 证据等级与表型

每条记录对 A 至 G 分别评价。A 涵盖实足年龄、年龄段及纵向衰老研究；B 涵盖卒中及脑血管风险；C 涵盖脑 MRI/CSVD；D 涵盖 AD、认知和痴呆；E 涵盖其他神经疾病；F 涵盖心血管、代谢和死亡；G 涵盖基础模型、跨域及多模态资源。G 的 Tier 3 可以是单中心资源，用作外部域或标注辅助，不能据此宣称有多个采集中心。

| 标记 | 在本库中的判断 |
|---|---|
| Tier 1 | 有明确的个体关联证据，并有可说明的公开或受控访问路径。需要正式审批也可满足。只对行内写明的终点成立，例如同期 CIMT、年龄段、SAD 病例 MRI 判读、某认知量表，各自均有不同适用范围。 |
| Tier 2 | 研究内曾做同人关联，但独立项目取像素/特定终点的权限或文件范围待证，或患者对应、标签交付、源数据复用权仍未核实。 |
| Tier 3 | 可辅助影像表征、血管/层分割、跨域泛化，或需合法取得父库像素的标注。 |
| Excluded | 对指定问题或对独立像素库明确排除，并保留理由。 |
| Unknown | 对该专题未建立判定；并非资源中没有该表型。 |

`topics.csv` 同时保留来源复核时的等级与统一的像素访问判定。后者用于 `master.csv`、HTML 和排名。例如 NHANES 有同人的分级与临床表，但像素路径不清，像素项目为 Tier 2。实际数据交付情况由 `image_access`、`label_access`、`pairing` 决定。未录证据的元数据为 `Unknown`；三值表型的未核实字段显示 `Uncertain`，证据栏为 `Unknown`。`Not available` 仅指已检查版本、字典或用途范围没有相应数据；`Confirmed` 保留具体粒度，包括自报、医疗编码、测量表或正式裁定等。主表内不存储任何个人诊断。

## 五维评分

只对有专题证据且进入科研候选池的资源排名，三个方向共有 83 个资源–任务组合。每一行保留具体研究终点、样本分母及评分依据。相同资源在不同方向可以得到不同的分数。分数是选题工具，属于本项目的可复现判断，不是研究质量认证或因果效应量。[资源判断输入](inputs/score_profiles.tsv) · [专题终点和人数输入](inputs/score_targets.tsv) · [计算代码](src/ranking.py)

| 维度（0–4） | 可复核的规则 |
|---|---|
| R 科学适配 | 4 表示任务的直接主要终点，如年龄配合重复影像或健康结局、前瞻卒中、明确 CSVD 参考标准或纵向痴呆；3 表示直接连续年龄、临床病例对照、脑影像表型或认知测试，包括当前引用的 AGES 与 CHS 横断面认知／痴呆分析；2 表示代理、既往自报、范围受限或桥接条件待证；1 表示只有年龄段等弱匹配。规则按终点解释，病例 MRI 摘要与完整影像在终点栏区分。 |
| L 标签丰富度 | 对该方向预定义的年龄、性别、共病、结局、随访等字段，只计 `Confirmed` 且适用于所评分终点的字段。计数为 k 时取 `min(4, ceil(k/2))`；完全无确认则为 0。各方向字段集合见代码。MCFI 中过于稀疏的自报共病不计入年龄方向的标签分；AGES 的串行 MRI、CHS 的总体临床事件随访不自动算作神经退行性终点随访。[逐项例外](inputs/score_label_omissions.json) |
| Q 队列质量 | 可证实的任务关联人数达到 100 和 1,000 各加 1。社区/人群抽样、可说明的质量控制、确认存在相关随访各加 1，总分上限 4。随访加分与 L 使用同一专题例外规则：对某方向排除的随访字段也不得为该方向的 Q 加分。仅有母队列、文件批次、未证实患者分组或未知分母不给规模分；已证实的病例子集可作为下界。`n_scope` 标明依据，`reported_n` 保留上下文人数，`n_supported` 是实际用于规模评分的人数。社区招募不等于全国代表性。 |
| X 访问可行性 | 4 表示有可说明条件的公开影像及标签路径；3 表示明确注册/附条件的文件路径，或有公开文件但需要进一步核验特定操作条件；2 表示有正式受理影像申请或具名团队的安全环境；1 表示联系作者、像素/授权范围未证；0 表示暂停新申请、无核实的像素路径、禁止独立使用或来源链未明。按一般适格科研团队评估；单位所在地的限制另在记录内说明。 |
| M 多中心价值 | 0 表示来源不清；1 表示单点或只能作为独立人群/设备域；2 表示有多种设备、族群或多个招募点之一；3 表示有明确的多中心项目或多个社区中心，并有来源说明；4 预留给同时具备可检验中心键和跨地区/设备分布的项目。本次没有资源因机构署名数量而得分。 |

科学分 = (40R + 25L + 25Q + 10M) / 4。近期实施分 = (25R + 15L + 10Q + 5M + 45X) / 4。二者均为 0–100；科学分保留 X 列但不对获取难度扣分。并列同分用相同名次。仅在人工标记了可实际使用的终点、专题是 Tier 1、R≥3 且 X≥3 时，才进入近期榜。某库公开了派生表或成像研究代码，不能凭此入榜；FDR26 的患者键和 ODIR 的许可即为两个未过门槛的例子。基础模型辅助项目与纯临床排除项保留在目录，但不给虚构的卒中或 AD 分数。

重新设计研究时，可先过滤终点再排序。例如，仅对 `incident stroke` 排序应剔除 `CIMT`、同期 CSVD 和仅有既往自报的行；只做连续年龄回归应剔除年龄段数据。小样本重测与建立广年龄范围基础模型是不同任务，应分别选队列。
